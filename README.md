# Reiner's AI Learning Journey

Catatan, latihan, dan progress belajar AI Engineering — dimulai dari Purwadhika Job Connector Program (kode bootcamp: **JCAIEH**), dan akan bertambah seiring sumber belajar baru ke depannya.

## Struktur

```
Purwadhika JCAIEH/
├── PANDUAN_LANJUT_BELAJAR.md          <- tracker progress & jadwal belajar
├── GUIDELINE_PENGERJAAN_EXAM.pdf      <- aturan resmi platform exam
├── python-exercise-materials/         <- demo & exercise .py/.ipynb dari kelas (tumbuh terus, lintas-module)
├── sql-exercise-materials-/           <- demo & exercise SQL dari kelas
├── Module 1/
│   └── Rangkuman_Obsidian/            <- vault Obsidian: catatan per sesi + Kamus & Cheatsheet + MOC
└── Module 2/                          <- (akan diisi seiring materi baru)
```

Sumber belajar AI lain di luar Purwadhika (kalau ada nanti) akan jadi folder baru sejajar dengan `Purwadhika JCAIEH/`.
